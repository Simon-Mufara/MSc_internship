🔧 WHAT WAS WRONG:
───────────────────────────────────────────────────────────────────────────────

PROBLEM: The code mixed better-sqlite3 syntax with sqlite3 driver

Better-sqlite3 uses synchronous API:
  db.prepare("SELECT ...").all()
  db.prepare("SELECT ...").get()
  db.prepare("INSERT ...").run()

SQLite3 uses callbacks:
  db.all("SELECT ...", params, (err, rows) => {})
  db.get("SELECT ...", params, (err, row) => {})
  db.run("INSERT ...", params, (err) => {})

SOLUTION: Use the async wrapper functions already defined in db.js:
  await allAsync(sql, params)
  await getAsync(sql, params)
  await runAsync(sql, params)
